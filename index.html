                                    Di menu atas Google Sheets, klik menu Ekstensi (Extensions) -> pilih Apps Script. 3

4

                            

                                
Terapkan Sebagai Web App (Deploy) — PENTING!

                                

                                    Klik tombol biru Terapkan (Deploy) di kanan atas -> pilih Penerapan Baru (New deployment) -> pilih jenis Aplikasi Web (Web App).
